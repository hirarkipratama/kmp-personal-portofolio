# Release checklist

- [ ] No placeholder or invented portfolio content.
- [ ] CV file is approved and download URL works.
- [ ] All project images and links resolve.
- [ ] Desktop/mobile responsive checks pass.
- [ ] Keyboard and reduced-motion checks pass.
- [ ] SEO metadata and crawler-visible content reviewed.
- [ ] Production Gradle build succeeds.
- [ ] Content validation and tests pass.
- [ ] `/admin/` access is restricted to the owner.
- [ ] CMS commit to `main` triggers expected build/deploy.
- [ ] Cloudflare Pages preview verified.
- [ ] No secrets or credentials committed.
- [ ] Known limitations documented.
